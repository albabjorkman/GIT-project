# Artdatabanken QGIS Plugin ReadMe
Unofficial plugin for extracting data from the Swedish Artdatabankens database.\
Created by three students in conjunction with the EXTP40 - GIT-project course at Lund University in 2025.

# Plugin Structure
The plugin consists of three different request types which utilizes either APIs available at Artdatabanken or the Species Observation System (SOS) WFS Service.
The two APIs used are getAreas() and ObservationsSearchByDwc.
